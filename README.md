# 拼音乐园 🔤

帮助一年级小朋友学好汉语拼音的手机网页应用（PWA）。
无需安装、无需上架应用商店 —— 手机浏览器打开即用，也可以"添加到主屏幕"像真正的 App 一样使用。

## 功能

| 模块 | 内容 |
|------|------|
| 认一认 | 23 个声母、24 个韵母（单韵母/复韵母/前鼻/后鼻）、16 个整体认读音节，点卡片听发音 |
| 拼一拼 | 声母 + 韵母 = 音节（如 b + à = bà 爸），配常见字和图，四选一练习 |
| 闯关大冒险 | 10 个关卡、混合题型（听音选卡、看图选音、拼读选字），星级奖励，进度保存在手机上 |

发音使用手机系统自带的中文语音合成（iOS / 安卓都内置），完全离线可用。

## 本地运行（开发）

```bash
cd pinyin-app
python3 -m http.server 8000
```

然后手机和电脑连同一个 Wi-Fi，手机浏览器访问 `http://<电脑局域网IP>:8000`
（电脑 IP 可用 `ipconfig getifaddr en0` 查看）。

> 直接双击 index.html（file:// 协议）功能也能用，只是没有"添加到主屏幕"等 PWA 特性。

## 部署到线上（免费方案任选其一）

- **GitHub Pages**：push 到仓库，Settings → Pages 开启即可，得到 `https://用户名.github.io/仓库名`
- **Vercel / Netlify**：拖拽 `pinyin-app` 文件夹即可部署

部署后用手机浏览器打开，在分享菜单里选 **"添加到主屏幕"**，就会获得全屏、带图标的 App 体验，
且缓存后**离线也能玩**。

## 如何修改内容（家长/老师）

所有学习数据都在 `index.html` 顶部 `DATA` 区域，直接编辑即可：

- `SHENG`：声母 + 示例词 + emoji
- `YUN_GROUPS`：韵母（按四组分类）
- `ZITI`：整体认读音节
- `SYL`：拼读音节库（声母、韵母、带调音节、汉字、词、emoji）
- `LEVELS`：关卡定义（可改关卡数量、顺序、题型比例）
- `Q_PER_LEVEL`：每关题目数量
- `AUDIO.rate`：发音语速（默认 0.72 放慢，可调 0.6～1）

## 已知限制 / 后续可升级

- 拼音的"纯声母"读音（如 b 的本音）语音合成无法完美发出，目前卡片点击会先读拼音再读示例词。
  若实际设备上读拼音效果不理想，可改成只读示例词，或后续替换成真人录音（把 `AUDIO.speak` 改成播放 mp3 即可，接口已集中封装）。
- iOS 的主屏幕图标：iOS 不支持 SVG 角标，如需精美图标可补一张 180×180 PNG 并在 `index.html` 中把 `apple-touch-icon` 指向它。
- 关卡进度保存在 `localStorage`，换浏览器/清缓存会重置。

## 技术栈

纯原生 HTML/CSS/JS，零依赖，单页应用。无任何网络请求，不收集任何数据。
